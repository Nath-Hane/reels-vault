# Video by ayzz.thedesigner

## Description
How these are built??🤯

A lot of people assume these kinds of websites are built with some insanely complex setup.

In reality, it’s mostly about having a clear process and not overengineering things.

Most of what you see here is built with Webflow.
For design and planning, we live in @figma and FigJam.
For building, @webflow or @framer .
For E-Com, obviously Shopify but then we need to code it in liquid.
But 90% Webflow.
And yes, we do use React too, but only when the project actually needs it, not just for flexing.

The tools aren’t the secret part.
Knowing when to use what is.

If you enjoyed this breakdown, you’ll probably like what I post next too.

## Transcription audio
If you want to build websites like this, or this, or this, and you want to know how they are all built and designed, the answer may honestly surprise you. We've been designing and developing these kind of websites in our agency and if you make till the end of this video, I will share the exact process and tools we use to design them. And you might not even need a lot of front end experience. So this is how it usually starts for us. Before we design anything, we just try to understand a few simple things. What the brand is about, what the website actually need to achieve, and what the user is actually supposed to do on the website. Based on that, we create a sitemap, basically deciding what pages we need, what goes on the homepage, and what actually deserves attention. We also do a little bit of competitor research, get some help from AI, and log this part first, and we use Figma or FigJam for this process. Once that's clear, we move into the design. This is where we collect all the assets, branding, visuals, everything, and start designing. Then we decide, do we need 3D here, 2D is enough, and where motion actually adds value. Everything here is designed in Figma, and we don't stop at just static screens. After designing, we create motion prototypes, sometimes directly in Figma, and sometimes in After Effects. Let's ask why. That single prototype does 3 things. First it shows the client how the website will actually behave after it's being developed. Second, we can showcase that same video on our portfolio or our Instagram page. And third, it's a clear reference for developer. We don't need to explain every animation to the developer, we can just send the video and that's it. Now here's the part most people don't expect. The majority of these websites, almost 90% are built on Webflow. And yes, you don't need heavy frontend experience. And you certainly don't need to build everything from scratch with code. Webflow handles layouts, responsiveness, and base interactions very well. For motion, we layer it with G-SAP, which is now basically a standard for scroll based animations and transitions. For smooth scrolling, we use tools like Lennis, for page transitions, library like Barba GS. And a lot of 3D looking stuff that you see, it's not actually 3D, it's just a smart use of 2D asset. Web profiles and videos with some depth and motion. If real 3D is needed, we add it, but only when it makes sense for the brand. So yeah, that's pretty much our process. And if you want to learn more about this stuff, then why you aren't following me.
