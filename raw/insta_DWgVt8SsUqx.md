# Video by vedant.design.tech

## Description
This design went viral, so here’s the exact process behind it.

Started by generating the base visual and a sci-fi variation using AI, then turned those static frames into a smooth flowing animation using Google Flow.

From there, built a custom layout in Figma using simple shape operations (nothing complex, just clean structure), added minimal UI elements to keep the focus on the motion.

Finally, moved everything into Framer, embedded the animation as a background, and turned it into a fully interactive hero section.

No crazy tools, just the right combination and flow.

I’ve shared all the prompts, images, and assets in the bio if you want to try it yourself.

## Transcription audio
This design went viral. Here's exactly how I made it. I've shared all the images and prompts in my bio. There's a Google Drive link with everything I used. First, open Gemini. Generate your first image using the first prompt. Next, use the second prompt to generate the sci-fi flower image. Make sure you upload the base image as a layout reference. Now, open Google Flow. Upload both images as your first and last frame. Use the video prompt to generate this smooth ground flow animation. Once that's done, move to Figma. Create a shape, duplicate it, use the Union tool from the top panel to combine them. Adjust the curves and make this custom layout. Add a few UI elements on top. Keep it minimal. Now, use the Figma to Framer plugin to move everything into Framer. Embed your video as the background and your site is ready to publish.
