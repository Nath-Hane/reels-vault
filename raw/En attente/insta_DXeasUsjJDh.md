## Description
Regex is the most underrated skill in cybersecurity.

You can automate your job with it. You can pull 1,000 IOCs from raw logs in seconds. You can spot leaked AWS keys before an attacker does. And most engineers never go past grep -i error.

7 regex patterns you'll use every week, each with a color-coded breakdown of what every bracket, anchor, and quantifier actually does:

-> IPv4 extraction from access logs
-> Email extraction from breach dumps
-> URL extraction from proxy logs and PCAPs
-> MD5 hash hunting, swap for SHA1 or SHA256
-> AWS access keys in repos and CI logs
-> Base64 payloads in malware and PowerShell
-> JWT tokens in auth logs and client-side code

Every slide shows the real command, the real output, and exactly what each regex piece means. No fluff, just the muscle memory that makes log review ten times faster.

Save it. Next log review, open the post, not Stack Overflow.
