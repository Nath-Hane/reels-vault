## Transcription audio
Je te montre la stack que j'utilise pour construire mon prochain SAS. C'est parti ! On commence par Next.js, le framework full-sac-react le plus populaire. Avec la dernière version, t'as une maire gestion du cache pour les composants et la navigation. Le framework te permet de faire des sites statiques optimisés pour le SEO, parfait pour des landing page, mais aussi des sites dynamiques pour le corps du SAS et les dashboard. Pour l'authentification, je pars sur Batorost. Pour moi, c'est le meilleur framework d'authentification type 3. J'ai la connexion par email-modepass, Google, Apple, Discord, GitHub et presque tous les réseaux sociaux. Mais c'est pas ski, authentification de facteurs, contrôle d'accès par rôle, gestion des organisations et plein d'autres fonctionnalités grâce à leur catalogue de plugins. Ce qui nous amène à Drizzle, un ORM pour communiquer avec notre base de données. Le truc cool, c'est que Batorost a un adaptateur Drizzle ou une maire intégration. Pour la base de données, je pars sur Postgres, resté sur Superbase ou Neon, pour commencer parce qu'ils ont un fritiaire qui génère. Abonne-toi si tu veux voir comment je construis ce SAS de A à Z. Pour la gestion d'appément, je pars sur strike. C'est un standard, c'est fiable et il y a une tonne de ressources pour l'intégrer proprement. Et en plus, il y a un plugin avec Batorost pour faciliter les abonnements et les paiements. On continue avec Chatsen côté Fronten, comme libraire de composants pour accélérer la création des interfaces. J'ai SAP pour ajouter des animations, Risen pour envoyer des mails, simples et efficaces. Et pour finir, je vais ajouter le support de services d'analytics comme Posthug, Le Zeeble, Datafast ou pourquoi pas Visitor et le Metapixel pour le tracking des campagnes de pub. Et pour développer tout ça, j'utilise Cloud Code avec un plugin que j'ai créé moi-même. Des skills et des agents custom pour aller plus vite et surtout faire du code sécurisé et bien architecturez. Si tu veux voir comment j'utilise cette stack et mon setup Cloud Code pour construire ce SAS, abonne-toi. C'était Nicolas, je fais une vidéo par jour, à demain.
